## ✅ ACCEPTANCE CRITERIA

### Given-When-Then Format

**Given** monitoring is configured
**When** system metrics are collected
**Then** dashboards should show:
- Real-time database performance (CPU, memory, disk, connections)
- Application performance (response time, error rate, throughput)
- Business metrics (purchases/hour, active users, revenue)
- Health status of all critical components
- Updated every 60 seconds with < 5-second latency

**Given** alerts are configured
**When** critical conditions occur
**Then** alerts should:
- Trigger within 2 minutes of threshold breach
- Be sent to on-call team (Slack, PagerDuty, email)
- Include context (what failed, when, severity)
- Have actionable recommendations
- Auto-resolve when condition clears

**Given** logging is enabled
**When** events occur in the system
**Then** logs should:
- Contain all relevant context (timestamp, service, level, message)
- Be centralized in CloudWatch Logs
- Be searchable and queryable
- Retained for 30 days (compliance)
- Exclude sensitive data (PII, passwords)

### Task 3.4.4: CloudWatch Insights Queries
- [ ] Create saved queries for common troubleshooting:
  1. **Errors in last hour**
     ```
     fields @timestamp, @message, error, severity
     | filter @message like /error/i
     | stats count() by severity
     ```
  2. **Slow queries**
     ```
     fields @timestamp, query, duration_ms
     | filter duration_ms > 500
     | stats avg(duration_ms), max(duration_ms), count()
     ```
  3. **Failed webhook processing**
     ```
     fields @timestamp, webhook_id, status, error
     | filter status != "success"
     | stats count() by error
     ```
  4. **Email delivery failures**
     ```
     fields @timestamp, recipient, status, reason
     | filter status = "failed"
     | stats count() by reason
     ```
  5. **Authentication failures**
     ```
     fields @timestamp, email, ip_address, attempt
     | filter attempt = "failed"
     | stats count() by ip_address
     ```
- [ ] Create custom metrics from logs:
  - [ ] Webhook success rate (%)
  - [ ] Email delivery rate (%)
  - [ ] Authentication success rate (%)
  - [ ] Average response time (ms)
