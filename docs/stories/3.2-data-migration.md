## ✅ ACCEPTANCE CRITERIA

### Given-When-Then Format

**Given** the production database is ready
**When** I run migration scripts
**Then** all data should be:
- Successfully transferred from source database
- Validated for completeness (no missing records)
- Validated for integrity (foreign key consistency)
- Logged for audit trail (who migrated what, when)
- Zero data loss (100% transfer success rate)

**Given** migration is complete
**When** I validate the data
**Then** all tables should have:
- Correct row counts (matching source)
- Valid timestamps (created_at, updated_at)
- Valid foreign keys (no orphaned records)
- Valid email addresses (format validation)
- Valid phone numbers (if applicable)

**Given** production data is loaded
**When** the application queries the database
**Then** it should:
- Return correct results matching source data
- Maintain referential integrity
- Support all features (reporting, analytics, customer lookup)
- Have no duplicate records
- Have no corrupted data
