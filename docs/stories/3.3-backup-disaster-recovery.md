## ✅ ACCEPTANCE CRITERIA

### Given-When-Then Format

**Given** automated backups are configured
**When** backup schedule runs
**Then** backups should be:
- Taken twice daily (06:00 UTC, 18:00 UTC)
- Stored in separate AWS region (S3 buckets in different regions)
- Encrypted with KMS encryption
- Retained for 30 days (automatic cleanup)
- Verifiable: Can be restored to test environment

**Given** point-in-time recovery is configured
**When** a database failure occurs at time T
**Then** recovery should:
- Restore database to any point within last 7 days
- Take < 30 minutes (RTO target)
- Lose no more than 1 hour of data (RPO target)
- Verify data integrity after restore
- Maintain all referential integrity

**Given** a disaster recovery procedure is documented
**When** primary database becomes unavailable
**Then** the procedure should:
- Define clear steps to switch to standby/restored database
- Require < 30 minutes to complete
- Update application connection strings
- Verify application connectivity
- Communicate status to stakeholders

**Given** replica/standby database is configured (if applicable)
**When** primary database fails
**Then** automatic failover should:
- Detect failure within 30 seconds
- Promote replica to primary automatically
- Update DNS/connection strings
- Resume operations with zero manual intervention
- Maintain data consistency (no data loss)
