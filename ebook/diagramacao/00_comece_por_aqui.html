3 Formas de Usar Este Manual

Perfil 1: "Quero Entender Tudo Antes de Agir"

Para quem:

  • Você gosta de saber por que algo funciona e como funciona antes de executar;
  • Você quer contexto, ciência, lógica por trás de cada protocolo;
  • Você tem tempo (60-90 minutos) para ler o manual completo.

Como usar:

  1. Leia os 8 capítulos na ordem (Capítulos 1-8);
  2. Destaque os pontos principais;
  3. No Capítulo 8, decida se vai fazer suas anotações de forma manual ou com app Primal;
  4. Execute a partir do Dia 1.

Vantagem: Você vai entender por que cada passo existe. Isso aumenta a adesão.

Desvantagem: Demora mais para começar.

Perfil 2: "Quero Executar Agora, Entender Depois"

Para quem:

  • Você quer ação imediata! Cansou de perder tempo!;
  • Você confia no sistema e só quer o passo a passo;
  • Você tem 15 minutos agora e quer começar amanhã.

Como usar:

  1. Pule para o final de cada capítulo;
  2. Leia apenas o "PROTOCOLO RÁPIDO" (resumo executável);
  3. Anote os 3-5 passos principais de cada capítulo;
  4. Execute imediatamente ou comece amanhã se precisar se programar;
  5. Volte e leia o capítulo completo depois, quando quiser entender o "porquê".

Vantagem: Você começa hoje. Momentum imediato.

Desvantagem: Menos contexto. Se der errado, você não sabe ajustar sozinho.

Perfil 3: "Quero Só o Essencial, Nada de Enrolação"

Para quem:

  • Você não tem paciência para teoria;
  • Você quer o mínimo viável que funciona;
  • Você prefere testar 7 dias e depois decidir se lê o resto.

Como usar:

  1. Leia apenas 3 capítulos:
    • Capítulo 2: 21 Dias (estrutura geral);
    • Capítulo 3: Protocolos Matinais (rotina de 12 minutos);
    • Capítulo 4: Nutrição Primal (janela alimentar de 8h);
  2. Execute só isso por 7 dias;
  3. Se funcionar, volte e adicione os capítulos 5-7;
  4. Se não funcionar, você desperdiçou 7 dias (não 21).

Vantagem: Teste rápido. Baixo compromisso inicial.

Desvantagem: Resultado limitado (você não está fazendo o protocolo completo).
